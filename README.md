# Amit Das — Portfolio

Personal portfolio site for **Amit Das** — AI Director & Creative Director (luxury, jewellery & fashion), grounded in thirteen years of filmmaking, cinematography and post.

A single, self-contained `index.html` — no build step, no dependencies.

## Run locally
Just open `index.html` in a browser.

## Deploy
- **GitHub Pages:** enable Pages on the `main` branch (root).
- **Vercel:** import the repo — it deploys the static site automatically.
